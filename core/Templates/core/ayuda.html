    Cómo iniciar sesión
    1. En la página principal, haz clic en Iniciar sesión.
    2. Escribe tu usuario y contraseña.
    3. Pulsa Entrar para acceder al panel.
    Cómo registrar un usuario
    1. Ingresa al módulo Usuarios.
    2. Haz clic en Nuevo usuario.
    3. Completa los campos obligatorios y guarda.
    4. Asigna el rol correspondiente.
    Cómo usar productos
    1. Abre el módulo Productos desde el menú lateral.
    2. Usa el buscador para localizar productos existentes.
    3. Crea, edita o activa/inactiva productos según necesidad.
    4. Verifica el mensaje de confirmación al guardar.
